# Mexico Jungle Tours MVP

Static MVP homepage for Mexico Jungle Tours, a premium jungle adventure landing page for Riviera Maya bookings and WhatsApp leads.

## Preview locally

Open `index.html` directly in a browser, or run a small local server from this folder:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080/`.

## Replace before launch

- WhatsApp placeholder: `https://wa.me/XXXXXXXXXXX`
- Stripe booking placeholder: `https://buy.stripe.com/PLACEHOLDER`
- Hero image/video placeholder: `assets/hero-jungle-cenote-placeholder.jpg`
- Open Graph image placeholder: `assets/og-jungle-adventure.jpg`
- Experience durations and prices
- TripAdvisor, Viator, Instagram and TikTok profile links
- Verified reviews, UGC and guest photos
- Map image or map link for Ruta de los Cenotes
- Business phone, address, coordinates, opening hours and price range in JSON-LD

## Deployment

This site is static HTML with TailwindCSS loaded by CDN. It is compatible with GitHub Pages and Cloudflare static hosting.
